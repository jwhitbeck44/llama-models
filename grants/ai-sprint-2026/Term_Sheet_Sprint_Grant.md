# Term sheet: AI Sprint Grant proposal, ENTP 3000

## Defined terms

| Term | Definition (source) |
| --- | --- |
| Course Learning Outcome 2 | "Explain the challenges and issues that entrepreneurs face when starting a venture." (Fall 2026 syllabus) |
| Founder Task | The weekly experiential assignment, scored on the Founder Task rubric (syllabus) |
| Founder Task rubric | Four criteria at 0 to 2 points (Evidence of the Act, Specificity, Framework Contact, Honest Reckoning) plus 2 points for Board presentation (rubric document) |
| Peer Advisory Board | Permanent group of about six students (syllabus); short form: Board |
| Board Rounds | In-class block where students present the completed task to their Board (syllabus) |
| Studio block | In-class block where the week's task is completed or designed (syllabus) |
| Machine Shop | Live, projected AI segment run by the instructor (syllabus) |
| Module Briefing | Pre-class reading that replaces a textbook (syllabus) |
| Readiness Check | Pre-class open-book quiz, 80% to pass (syllabus) |
| DIY Mentor Project | Two-week midterm, Modules 7 and 8 (syllabus) |
| Final Pitch | 3 to 5 minute solo venture pitch: problem, solution, business model (syllabus) |
| Final Exam | DIY Case Study, open-note, AI not permitted; sections Context, Framework Application, Business Model Canvas, Personal Application (syllabus) |
| Phase 3 | Modules 12 to 15, The Build (syllabus) |
| test version | The artifact a student builds with the build tool: a landing page, a sign-up form, or a clickable prototype (this proposal) |
| build tool | An AI tool that produces a working web page or prototype from a written description (this proposal) |
| AI Check-In survey | Anonymous week 1 survey of students' AI use, including paid versus free tools (course) |
| the gap between ideation and execution | One of the challenges named in Course Learning Outcome 2 (syllabus) |
| people outside the class | Anyone who is not enrolled in the section; Board members do not count (this proposal) |

## Do not use

`MVP` / `minimum viable product` (use "test version"), `vibe coding` (except in a quoted course name), `evidence theater` (except quoting Blank), `AI sandwich` (except naming McGuire's award), `pod`, `stakeholder panel`, `persona`, `validate` / `validation` (use "test"), `novel` (say what is new), `leverage`, `empower`, `robust`, `rich`, `transformative`, `innovative`, `cutting-edge`, `hands-on`, `real-world` (use "outside the class" or "real people"), `scaffold` / `scaffolded`, `guardrails` (except quoting Bastani's title)
